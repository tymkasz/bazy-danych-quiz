# Bazy Danych - Quiz Egzaminacyjny

Zbiór interaktywnych pytań powtórkowych z przedmiotu **Bazy Danych**. Projekt stworzony w celu ułatwienia nauki do egzaminu.

## Link do quizu
**[Rozpocznij Quiz](https://tymkasz.github.io/bazy-danych-quiz/)**

## O projekcie
Quiz zawiera ponad **180 pytań** pokrywających cały zakres materiału, w tym:
* Modele danych (Relacyjny, E-R, NoSQL)
* SQL (DQL, DML, DDL)
* Normalizacja (1NF, 2NF, 3NF, BCNF)
* Transakcje i ACID
* Indeksy i optymalizacja
* Bezpieczeństwo i uprawnienia
* ORM i integracja z aplikacjami

## Jak uruchomić lokalnie?
Jeśli nie chcesz korzystać z wersji online, możesz pobrać projekt na dysk:
1. Kliknij zielony przycisk **Code** -> **Download ZIP**.
2. Rozpakuj archiwum.
3. Otwórz plik `index.html` w dowolnej przeglądarce.

## Dostęp
Wersja online jest zabezpieczona prostym hasłem, aby ograniczyć dostęp do grupy studenckiej.
